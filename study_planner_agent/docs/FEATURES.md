# Features Documentation

## 1. Advanced Scheduling
*   **Dynamic Time Allocation**: Calculates study hours based on topic count, difficulty, and days until exam.
*   **Peak Hours Optimization**: Schedules sessions during user's preferred times (Morning, Afternoon, Evening).
*   **Exam Prep**: Automatically reserves 2 days for revision and 1 day for mock tests before exams.
*   **Weekly Checkpoints**: Adds a progress review slot every Sunday evening.

## 2. Rescheduling & Adaptability
*   **Conflict Detection**: Identifies missed sessions and their impact.
*   **Smart Alternatives**: Suggests makeup slots (e.g., weekends) to keep the plan on track.

## 3. Progress Tracking
*   **Visual Reports**: ASCII-based progress bars for each subject.
*   **Weak Area Identification**: Highlights topics needing more attention.

## 4. Notifications & Motivation
*   **Reminders**: Alerts for upcoming sessions.
*   **Motivation**: Personalized messages to boost morale.

## 5. User Customization
*   **Flexible Inputs**: Supports any subject/topic structure.
*   **Preferences**: Customizable daily limits, session durations, and break times.
